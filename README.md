# BBYLW · w404.nyc.mn

Personal website for [@bbylw](https://github.com/bbylw), hosted on GitHub Pages at [w404.nyc.mn](https://w404.nyc.mn/).

## Features

- **Equalizer-Bar Sculpture Hero**: Pure Canvas 2D pixel/luminance grid engine (`js/equalizer-stage.js`) seamlessly matting monochrome sculptural portraits onto `#0F0F13` with staggered wave reveals, chromatic spectrum edges, pointer disturbance, and optional Web Audio harmonic pulse (`js/ambient-audio.js`).
- **Kinetic Headline Scramble**: Frame-synchronized 3-line display scramble (`js/text-scramble.js`) with EN / 中文 bilingual support.
- **Selected Works & 16-Portal CN Docs Network**: Filterable, keyboard-searchable directory (`/` to focus) showcasing open-source tools and live Chinese documentation portals (`js/data.js`).
- **Zero-Build Static Architecture**: Pure HTML, modern CSS, and native ES modules — ready for GitHub Pages without bundlers.
